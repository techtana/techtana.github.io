# 📘 Minimal Math for Control + SPC
### Section A — Basic Statistics (Mean, Variance, SPC)
1. Given measurements: `102, 98, 100, 105, 95`. Compute the mean.
2. Using the same data, compute the sample variance.
3. If `USL = 110`, `LSL = 90`, and the process `σ = 4`, compute Cp.
4. Compute Cpk for:
   * mean = 100
   * USL = 110
   * LSL = 90
   * σ = 5
5. A process has long-term sigma = 6 and short-term sigma = 3. What does this typically indicate?
6. An I-chart shows points with no trend but frequent jumps > 3σ. What does this usually indicate?
7. List two reasons why incorrect SPC subgrouping is harmful (e.g., mixing wafers from different tools).

### Section B — Discrete-Time Thinking
8. A process follows: `y[k] = 0.7*y[k–1] + 2*u[k]`. Given `y[0] = 10`, `u[1] = 1`, compute `y[1]`.
9. In one sentence, explain why we use difference equations in control engineering.
10. Compute `Δy = y[k] – y[k–1]` for `y[k–1] = 104`, `y[k] = 109`. What does this represent physically?

### Section C — Regression & Correlation (for ARX / FF)
11. Given X = `[1, 2, 3]`, Y = `[2, 4, 7]`, compute the least-squares slope.
12. A feed-forward variable has correlation `r = 0.05` with the output.Should you use it? Why or why not?
13. Given prediction errors: `2, –1, 3, –4, 0`, compute the RMSE.
14. If regression residuals show autocorrelation, what does this tell you?
    
### Section D — EWMA & Filtering

16.  If λ increases, what happens to responsiveness and noise sensitivity?
17.  A median filter is applied to the window `[101, 500, 102]`. What is the filtered value?

### Section E — Practical Control Math
18. For a PID loop: `Kp = 2`, `error = –5`. Compute the proportional term.
19.  A process has mean = 100 and a step disturbance shifts output to 107. What is the bias?
20.  Metrology delay is 3 wafers. How many past values must your ring buffer store?
